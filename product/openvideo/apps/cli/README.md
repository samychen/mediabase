# @openvideo/cli

The product host entry: a `BootIdentity` (`openvideo` / `OPENVIDEO_` /
`~/.openvideo` / profile key `openvideo`) and a thin bootstrap over
`@mediabase/boot` — the same four jobs the base CLI does. The profile template
composes `@mediabase/bundle-app` then `@openvideo/bundle-app`; this
package.json is the installation ANCHOR bare row names resolve from.
