mediabase — 分发物许可声明 / Distribution license notice
=========================================================

本模板默认**不**捆绑任何原生二进制:app bundle 里只有 MIT 的自有代码
(`@mediabase/*`、apps/、scripts/)与 npm 运行时依赖(全部 MIT)。因此
**默认分发物整体仍是 MIT**,见 LICENSE-MIT.txt。

This template bundles **no** native binaries by default: the app bundle contains
only MIT-licensed first-party code (`@mediabase/*`, apps/, scripts/) and npm
runtime dependencies (all MIT). The default distribution as a whole is therefore
still MIT-licensed — see LICENSE-MIT.txt.

若你的产品通过 `PRODUCT.resources` 追加了引擎 / ffmpeg 等原生二进制,则**分发条款由
那份二进制决定**,并可能把整个分发物拉成 GPL:请在你的消费仓里维护本文件(而不是在这里
改),并至少覆盖下节各项。

If your product appends native binaries (an engine, a bundled ffmpeg) via
`PRODUCT.resources`, the distribution terms are decided by **that** binary and may
make the whole distribution GPL. Maintain this notice in your consumer repository
instead of editing it here, and cover at least the items below.

第三方组件 / Third-party components
-----------------------------------
完整清单见随包的 NOTICE.md(由 `pnpm run notice` 生成)。默认基座只有 npm 运行时依赖,
全部 MIT。

The full list ships as NOTICE.md in this bundle (generated by `pnpm run notice`).
The default base has npm runtime dependencies only, all MIT.

加了原生二进制时,你还要覆盖 / When you add native binaries, also cover:
  - 每个原生组件及其许可(FFmpeg / x264 / 系统库…),逐项注明来源与版本
  - 构建参数:静态链接 GPL 组件会使二进制整体按 GPL 分发
  - 对应源码 / Corresponding source:GPLv3 要求向接收者提供对应源码或书面要约
    (源码归档、该次构建的 configure 参数、可重建同一二进制的构建脚本)
  - 随包附 GPL 全文与 MIT 全文(licenses/ 目录)

⚠️ 注意 / Caveat
----------------
分发物**不得**包含 `--enable-nonfree` 的 FFmpeg 构建(如 fdk-aac):按 FFmpeg 自身的
说明,此类构建不可再分发。`scripts/check-native-licenses.mjs`(`pnpm run check:native`)
可在打包前拒绝这种产物,`prepare-ffmpeg.mjs` 也会拒绝捆绑它;若本包内意外含有,请立即重建。

A distribution must **not** contain an FFmpeg build made with `--enable-nonfree`
(e.g. fdk-aac): such builds are unredistributable. `scripts/check-native-licenses.mjs`
(`pnpm run check:native`) refuses such an artifact before packaging, and
`prepare-ffmpeg.mjs` refuses to bundle one.
