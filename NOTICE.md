## FFmpeg cone (via MediaComponent)

Last engine configure: `AVSTUDIO_USE_MEDIACOMPONENT=ON`, `MEDIACOMPONENT_ROOT=/Users/chensi/develop/MediaComponent`.

When MediaComponent is enabled, the engine statically links these into one binary:

- avformat avcodec avutil swscale swresample avfilter avdevice postproc (FFmpeg)
- x264 (GPL, --enable-gpl 带入)
- fdk-aac (非自由, --enable-nonfree 带入)
- vpx opus srt rist mbedtls mbedx509 mbedcrypto yuv bz2 z iconv curl ssl crypto

**Their licenses are not knowable from this checkout** — they follow the FFmpeg build
MediaComponent ships. On the machine this file was generated from that build was
configured with `--enable-gpl --enable-nonfree`, which makes the resulting binary GPL
and, per FFmpeg's own terms, unredistributable. Read `docs/LICENSING.zh.md` before
distributing an installer.

## ffmpeg binary bundled into the desktop app

`packaging/desktop-electron/scripts/prepare-ffmpeg.mjs` copies one ffmpeg executable
into the app bundle. It prints a warning when that build carries `--enable-gpl` or
`--enable-nonfree`; set `AVSTUDIO_BUNDLE_FFMPEG=0` to ship without it (the app then uses
the user's own ffmpeg).

## MediaComponent itself
